### 🔭 Featured project

**[ct-hunter](https://github.com/TU-USUARIO/ct-hunter)** — pre-attack infrastructure hunter.

Most threat intel is something you consume. This one produces its own. It watches **Certificate Transparency logs** in near real time, flags **typosquatting** and lookalike domains before they're ever used, and then runs them through layered detection, external verification and visual comparison. Confirmed cases end up in an infrastructure correlation graph, a dashboard and a per-case report.

The idea: catch the attacker while they're still setting up the stage.
